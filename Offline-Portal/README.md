# portal_offline (stable MVP)

Flutter package: **portal_offline** — Field Service Corp **local-first** Windows/desktop line (`portal_offline.exe`).

## Product intent: offline-capable **and** online

This program is meant to **run in the field without relying on connectivity** (local database, on-device assets). It is **not** meant to be **offline-only**: when the network is available, it must support **sync**, **backend/API** use, and other connected capabilities—without making offline mode a degraded or incomplete product.

Development of new hybrid behavior happens in **`H:\FSC-Portal\FSC-Portal`**; promote here when stable. See **`H:\FSC-Portal\DEVELOPMENT_GUIDE.md`** (Connectivity model, Golden Rule).
